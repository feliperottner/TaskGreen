# 📲 TaskGreen

**TaskGreen** é uma aplicação **mobile** de gerenciamento de tarefas desenvolvida com **React Native** e **Expo**. A proposta do app é oferecer uma solução simples e intuitiva para que os usuários possam organizar sua rotina de maneira prática e eficiente.

## 🧩 Funcionalidades Principais

- ✅ Criar, listar e excluir tarefas
- 📅 Selecionar data e hora para cada tarefa
- 🚦 Definir o nível de prioridade da tarefa
- 🌙 Interface clean e responsiva
- 🔗 Integração com API externa (em breve)
